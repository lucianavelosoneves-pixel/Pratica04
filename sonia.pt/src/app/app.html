Entrar no GitHub → *New repository* 2. Nome: pratica03 3. Marcar *Add a README file* 4. Clicar em *Create repository* 5. Botão *Code* → aba *SSH* → copiar o endereço ## 2. CMD – clonar 1. Abrir o CMD (tecla Windows → digitar cmd → Enter) 2. Ir até a pasta: cmd cd C:\dev\lixo 3. Clonar: cmd git clone git@github.com 4. Entrar na pasta e abrir no VS Code: cmd cd pratica03 code . ## 3. VS Code – 1º commit 1. Editar o README.md → escrever treinando git extension → salvar (Ctrl+S) 2. Git Extensions → abrir o repositório C:\dev\lixo\pratica03 (na segunda opção, vai procurar até achar sua pasta. dá um clique e depois abrir pasta - atenção nisso-) 3. *Commit* → *Stage all* → mensagem 1º commit → *Commit & push* ## 4. Terminal do VS Code – projeto Angular e cabeçalho 1. VS Code → *Terminal > New Terminal* cmd ng new sonia.pt cd sonia.pt ng generate c /header/ 2. Git Extensions → *Commit* → *Stage all* → criando cabeçalho → *Commit & push* ## 5. Terminal do VS Code – principal cmd ng generate component main Git Extensions → *Commit* → *Stage all* → criando o principal → *Commit & push* ## 6. Terminal do VS Code – rodapé cmd ng generate component footer Git Extensions → *Commit* → *Stage all* → criando rodapé → *Commit & push* ## 7. GitHub – conferir 1. Atualizar a página do pratica03 2.
